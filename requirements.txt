#

# controller:
#
#     pip install -r requirements.txt
#
# That pulls in the ViGEmBus kernel driver and will open a Windows installer
# window (needs admin approval — no reboot required). Afterwards, restart
# bridge.js and it switches to gamepad mode automatically.
#
# Note: browsers cannot see the virtual pad, so this only helps native games.
# See the "Why browser games need their own mode" section of README.md.
